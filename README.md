# CinemaFun

CinemaFun — это веб-сайт кинотеатра, разработанный на HTML, CSS и JavaScript.

## Возможности

* Просмотр афиши фильмов
* Поиск фильмов
* Информация о фильме
* Выбор мест в кинозале
* Бронирование билетов
* Сохранение билетов через LocalStorage
* Контактная форма
* Работа с API

## Используемые технологии

* HTML5
* CSS3
* JavaScript
* Fetch API
* LocalStorage
